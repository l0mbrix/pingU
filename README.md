# pingU
A small useless bot to ping your Discord friends.

# How does it work?
This small Bot is designed to ping friends on Discord with a funny gif asking them to play. It's a very small scope project with a fairly clean code and only a few options (for now). This Bot was created as a joke for my friends and is not customisable yet!
